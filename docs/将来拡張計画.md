## 3. 受け入れ計画

| 計画ID | 条件 | 期待結果 |
| --- | --- | --- |
| DIR-PLAN-0004 | 500000 bit/sのBUS-Aと250000 bit/sのBUS-B、GW出力容量2 | BUS-A受信完了後にGW処理時間を経てBUS-Bで送信要求が発生し、各バスの転送時間をそれぞれのビットレートで計算 |
| DIR-PLAN-0005 | BUS-Bだけを高負荷にする | GWのBUS-B向けキューに待ち・容量超過が発生し、BUS-Aの仲裁・占有状態はBUS-Bと独立して進行 |
| DIR-PLAN-0006 | 1入力から2出力ポートへの複製 | 新しい2要求IDが共通originを持ち、それぞれの成功・破棄と母数を別に記録 |
| DIR-PLAN-0007 | 非循環の3段GW経路を設定、hop上限2 | 3回目のGW転送をdropped_hop_limitとして終了し、有限の処理で結果を取得 |
| DIR-PLAN-0008 | 旧単一バス入力を1.0.0へ入力 | 仮想イベント順、CRC・転送時間・計測値が旧プロファイルと一致 |
