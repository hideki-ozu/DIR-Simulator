# Dynamic Ethernet / TSN product acceptance fixtures (2026-10-08)

文書ID：`fixture-acceptance-dynamic-tsn-2026-10-08`

These 59 complete INI/NED/model/workload cases execute the native `ethernet.l2.dynamic.v1` or `ethernet.tsn.v1` profile through `prepare` → the registered staged network engine → schema-2 output. `expected.json` declares independent integer timing and policy expectations. `strict-negatives.json` declares 59 individual invalid-input patches to valid fixtures; the integration test materializes each complete patched input, sets a 1 ps horizon, and asserts preparation rejection. Invalid scheduled workload entries are moved beyond that horizon; invalid controls are also checked with empty generators.

Run from the repository root:

```sh
PATH=/home/hideki/.cargo/bin:$PATH cargo test --locked -p dir-simulator --test acceptance_dynamic_tsn -- --nocapture
```

The test retains actual five-file outputs under `/tmp/dir-acceptance-dynamic-tsn-runs/`, per-case output references under `/tmp/dir-acceptance-dynamic-tsn-cases/`, and invalid-input diagnostics in `/tmp/dir-acceptance-dynamic-tsn-strict-negatives.json`. The execution handoff is `/tmp/dir-acceptance-dynamic-tsn.json`. The fixtures themselves contain no product-derived expected timestamps.

`down-at-sof` characterizes processing completing at 611000 ps: phase-0 down precedes the routing lookup, so the reception has `known_egress_ineligible`, no new output copy, no SOF, and no downstream reception. `queued-linkdown-at-release` separately supplies the stronger queue-drop case: a second copy is already queued at 100000 ps; the first copy releases at 672000 ps, the link goes down at that same time, and the second copy drops `link_down` without SOF.

The numerical PSFP table's three identical ingress arrivals at time 0 cannot be generated by three serialized frames on one native ingress link. The production planner unit suite executes that exact simultaneous vector; the native five-frame fixture independently accounts for physical arrival times 576000, 1248000, 1920000, 32576000 and 96576000 ps. Pure planner fault injection, fractional/saturation vectors, topology parallel/disconnected cases, static FDB priority, MAC move, and per-callback reservation failures are covered by the separately executed dynamic/TSN/staged unit suites, not claimed as CLI injection here. The current native workload generates valid FCS and implicit source MACs, so corrupt-FCS admission and direct source-MAC spoofing/move lack a native input fixture. Browser/old-profile full regression and additional failure injection remain the parent verification stream. These results do not claim IEEE/BPDU/IGMP/MLD/MVRP conformance or large-scale performance.
