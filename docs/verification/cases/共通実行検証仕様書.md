配送の再現性は同じ初期予約から2回実行し、on_eventの対象順、EventKey、効果の呼出し順、成功journalの値を比較する。時刻10のcallbackで「時刻11へA配送→同じ時刻11へB配送→二つの観測」を順に提示した場合、AのsequenceがBより小さく、観測のeffect_seqも提示順となる。二つ目の配送schemaを不正へ変えた反例では両配送と両観測を公開せず、成功件数と直前journalを保持する。scheduler単独の順序だけでDIR-REQ-0007・0031・0045・0046の配送側分担を合格としない。
